# Lab 02: Express and Mongoose Service Request Server

This lab is the Express, MongoDB, and Mongoose version of the Smart Campus Service Request server.
The initial skeleton provides health and unknown-route handling; models and CRUD endpoints will be
added in later steps.

## Run and test

Run these commands from this directory:

```powershell
npm install
npm start
npm test
```

Copy `.env.example` to `.env` and set `MONGODB_URI` before starting the server. `PORT` defaults to
`3000`.

## Development

```powershell
npm run dev
npm run lint
npm run format:check
```
