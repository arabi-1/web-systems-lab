# Lab 01: Service Request Server

A service request server built with Node.js core modules only (`http`, `fs`). No Express, no database, no frameworks. Part of [web-systems-lab](../../README.md).

## Run

    npm start

The port comes from `PORT` (default 3000). See `.env.example`.

## Test

    npm test

## Status

In progress. The server skeleton answers every route with a JSON 404. Routing and storage come in the next PRs.
